Bloom & Cradle Documentation

Everything you need to launch, rebrand, customize colors/fonts, replace photographs, and deploy your multi-page Gynecology & Maternity Clinic website.

1. Installation & Quick Start

This project is built with pure semantic HTML5, CSS3, and vanilla ES6+ JavaScript. There is no build step, bundler, or Node dependency required to run the site.

  • Direct Local Launch: Double-click root index.html or open pages/index.html directly in Chrome, Safari, Edge, or Firefox.
  • Local HTTP Server: Run npx serve . or python -m http.server 8080 from the project root.
  • Static Hosting Deployment: Upload the root folder directly to Netlify, Vercel, GitHub Pages, Cloudflare Pages, AWS S3, or any standard cPanel web host.

2. Customization Guide

Brand Name & Copy

Search for TODO: across the project to replace the working brand name "Bloom & Cradle Women's Health & Maternity Clinic", emergency numbers, and canonical URLs.

Color Palette ("Blush, Plum & Champagne")

Edit `:root` CSS variables in assets/css/style.css (light mode) and assets/css/dark-mode.css (aubergine dark mode `#1B0E19`).

Self-Hosted Fonts & SVG Icons

Font files (Fraunces, Plus Jakarta Sans, Caveat) are self-hosted in assets/fonts/. All UI icons are stored in assets/icons/icons.svg.
